# Analysing Students' Mental Health Using SQL

**Platform:** DataCamp
**Tools:** PostgreSQL, SQL
**Project Type:** Data Analytics Portfolio Project

## Project Overview
Analysed 286 student records to explore relationships between length of stay and student mental health indicators.

## Skills Demonstrated
- SQL aggregation and grouping
- Data exploration and analysis
- Trend identification
- Interpretation of analytical results
- Recognition of small-sample limitations

## Key Areas Investigated
- Acculturative stress
- Social connectedness
- Length of stay
- Student wellbeing indicators
